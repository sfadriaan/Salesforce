# Salesforce Admin Guide

## Login and Setup

To begin, contact your **Salesforce administrator** for account credentials. This is crucial for security and compliance.

### Routine Tasks

After logging in, the **Salesforce admin** handles routine user provisioning.

If the user count is high, it's okay for the **admin** to delegate some tasks. The **administrator** only deals with high-level permissions.

We will use the term **admin** frequently throughout the rest of this topic. The system **admin** is often busy.
