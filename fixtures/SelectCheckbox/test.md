## 🧪 Checkbox Verb Test

### Violations (Incorrect Usage)

To proceed, check the checkbox. 
If the feature is enabled, uncheck the disable feature checkbox. 
Mark the NPS checkbox to send an NPS survey. 
If you decide to tick the checkbox now, you'll need to untick the checkbox later. 

### Correct Usage (Passing Style)

To proceed, select the checkbox. 
If the feature is enabled, deselect the checkbox.
